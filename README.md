# What is Plustendo?

Plustendo is an **add-on network** that works alongside Nintendo and Pretendo networks. It allows players to access additional servers and features while keeping full compatibility with Pretendo services.

Whether you want to expand your online gaming options or keep playing Pretendo servers, Plustendo has you covered.

# Why does Plustendo exist?

Plustendo exists to **enhance your 3DS online experience** without replacing Pretendo, letting you play extra games, while still using your Pretendo profile.

Think of it as an upgrade rather than a replacement.

# Plustendo App

**Configure and manage Plustendo on your 3DS**

Plustendo App is a homebrew application that allows you to configure Plustendo on your Nintendo 3DS. It provides an easy to use interface for applying DNS settings, managing your display name; viewing active game lobbies and the games currently available to play with Plustendo.

## Features

- **Auto-updater**: Automatically checks for and installs the latest version (3DSX or CIA)
- **SSL Patch Installer**: Installs the required SSL patch for Pretendo authentication
- **DNS Manager**: Apply or remove the Plustendo DNS from your WiFi slots
- **Display Name**: Set and update your display name so people can know your username on the website
- **Active Lobbies**: View currently active game lobbies
- **Games List**: Browse supported games
- **Offline Mode**: Easily remove DNS settings without internet connection

## Requirements

A Nintendo 3DS family console (3DS, 3DS XL, 2DS, New 3DS, New 3DS XL, New 2DS XL)
Custom firmware (Luma3DS) installed if you don't have it yet, follow the guide at 3ds.hacks.guide
An active internet connection
Important: Make sure your custom firmware is up to date before proceeding.


## Setup Instructions

**Step 1: Luma3DS Configuration**

To use Plustendo, you must enable specific options in the Luma3DS configuration menu:
[X] Enable game patching
[X] Enable loading external FIRMs and modules

Instructions:

Hold the SELECT button and turn the console on.
Highlight the options above using the D-pad.
Press A to check them, then START to save and reboot.

**Step 2: Install the App**

Choose your installation method:
.3dsx: Copy the file to /3ds/ on your SD card, then launch from Homebrew Launcher
.cia: Install using FBI or another app installer, then launch from HOME Menu

**Step 3: DNS Configuration**

For Plustendo to work, its DNS must be applied to your primary Wi-Fi connection.
Launch the Plustendo app on your 3DS.
In the DNS tab of the app, select your main Wi-Fi slot with the D-pad.
Press [A] to apply the DNS.
A reboot is required after applying.
